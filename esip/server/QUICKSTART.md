# 🚀 Quick Start - 3 Commands

## Get your backend running in under 2 minutes!

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Setup Database
```bash
npm run db:push
```

### Step 3: Start Server
```bash
npm run dev
```

---

## ✅ That's it!

Your server is now running on: **http://localhost:3001**

Connected to: **Supabase PostgreSQL Cloud**

---

## 🧪 Test It Works

```bash
# Test database connection
npm run test:db

# Open database GUI
npm run db:studio
```
